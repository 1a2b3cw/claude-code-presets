# 移动端安全规则（必须遵守）

## 密钥与存储
- 客户端 bundle 中不能放服务端密钥。
- `EXPO_PUBLIC_` 变量视为公开信息。
- refresh token、设备凭据等敏感数据放 SecureStore 或平台安全存储。
- AsyncStorage 只存非敏感偏好和小体量缓存。
- 日志中不得输出 token、个人身份信息、定位、联系人或原始文件路径。

## 权限与隐私
- 权限请求必须由用户动作触发，并在 UI 中说明用途。
- 拒绝权限后提供降级路径或设置入口。
- 只声明实际使用的权限。
- 相机、相册、位置、通知、麦克风等权限文案必须与功能一致。

## 网络
- 认证、支付、AI API 等私密能力经后端代理，不从 App 直连敏感服务。
- API 错误转换为用户可读信息，避免暴露内部栈、SQL、云资源名。
- 上传文件前校验类型、大小和用户意图。
