# 设备验证规则（必须遵守）

## 验证层级
- 纯 UI 和导航变更至少在 iOS/Android 模拟器各验证一次。
- 涉及相机、通知、定位、文件、分享、深链、后台任务时必须做真机验证。
- 涉及原生模块、config plugin、EAS 配置时使用 development build 验证，不只用 Expo Go。
- 发布前必须验证 production 或 preview 构建产物。

## 矩阵
- 小屏手机和大屏手机都要检查布局。
- iOS 和 Android 都要检查返回、键盘、权限和状态栏。
- 深色模式、系统字体放大、弱网/离线至少覆盖核心流程。

## 记录
- tasks 或发布记录中写明验证设备、系统版本、构建类型和结果。
- 未验证项必须明确标为风险，不假装通过。
