# 移动端 UI 规则（必须遵守）

## 布局
- 所有首屏和底部交互都要考虑 safe area。
- 内容不能被状态栏、导航栏、底部手势区或键盘遮挡。
- 固定格式控件要有稳定尺寸，避免加载、hover/press、错误文案导致布局跳动。
- 移动端优先单列布局；复杂信息用分组、tabs、sheet 或分步流程。

## 触控
- 常用触控目标建议至少 44x44 pt。
- 可点击元素必须有 pressed/disabled/loading 状态。
- 危险操作需要明确确认或撤销能力。
- 手势不能成为唯一操作路径，关键操作要有可见按钮。

## 文案和可访问性
- 按钮文案短而具体。
- 图标按钮必须有 accessibility label。
- 文本与背景对比度至少达到 WCAG AA。
- 支持系统字体缩放，不用固定高度裁切文本。
- 深色模式下检查背景、边框、阴影和禁用状态。

## 表单和键盘
- 输入框必须处理 focus、error、disabled、loading。
- 键盘弹出时，主要输入和提交按钮不能被遮挡。
- 数字、邮箱、电话等字段使用合适 keyboard type。
- 错误提示靠近字段，并保持可读。
